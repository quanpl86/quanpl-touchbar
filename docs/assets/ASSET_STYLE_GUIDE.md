# Asset Style & Production Guide v1.0
Status: DRAFT (production target) — all source asset visuals are new project-authored material, NOT copied from reference repo.

## Visual language
Pixel-art 2D, modern-flat readable silhouette, dark black/navy or bright environment with strong contrast. 1 art pixel maps to 4 physical px at nominal @2x scale: draw source art on 20×11 (actor) or 8×8 (collectible) logical grid. Nearest-neighbor, hard edges, no painterly blur, no photorealism. Palette per pack max ~12 opaque colors plus transparent, shadow and 1 highlight. Always preview at 60px physical height.
Always preserve legibility of head/body and eyes at actual Touch Bar height; avoid one-pixel dark details on black background.

## Files + naming
- Source SVG masters: `assets/source/<category>/<id>--<state>--fNN.svg`
- Pack manifests: `assets/manifest/characters/<id>.json`
- Exported PNG per frame: `assets/export/<category>/<id>/<state>/fNN.png` (generated by pipeline)
- Master asset IDs snake_case; asset filenames kebab-case; state lowercase.
- Every frame same canvas (e.g. 20x11 art px) regardless of pose, with bottom-center pivot/anchor [0.5,1.0]. Do not crop animated frames independently.
- Mirror walk sprites in runtime only if asymmetry-free; if asymmetric, separate direction assets.

## Animation guidelines
Idle 4 frames @4–6 fps; Walk 6 @8–10 fps; Happy 5 @10 fps one-shot; Sleep 4 @3–4 fps; Jump 6 @10–12 fps one-shot. These are *design targets*, not app's current frame rate. A control timeline decouples logical animation speed from rendering cadence.
Tap interrupts most states with Happy, then returns to previous long-running state. Higher-priority modal state can prevent interruptions. Repeat tap debounce proposed 200ms; long press proposed 500ms and swipe horizontal >=30pt; validate on hardware.

## Terrain
Tile loop horizontally (32×15 art px) or background panorama crop by viewport. Do not stretch landscape textures. Static decorations noninteractable; interactive world props use an independent sprite.
Ground height recommended 2..3 art px from bottom of tile; leave upper region for sprite silhouette; world ground Y coordinates normalized to visible region.

## Item classes
- Collectible: visual 6×6 or 8×8 art px, pickup effect 3–6 frames, small-hit visual but larger X hit slab.
- Interactive: chests / levers 12×10 art px; state idle/open/active as frames, interaction cooldown.
- UI: use high contrast native text; icon source SVG or precise pixel-art PNG; separate visual and hitbox.
- FX: alpha sprites 4×4 / 8×8, capped duration 200–700ms; cannot steal taps.

## Export validation
JSON schema validation; frame counts matching files; dimensions consistent for all frames in state; sprite nonempty alpha; transparency outside artwork; all declared anchors within 0..1; no aliasing/accidental blur; actual physical Touch Bar preview PNG/GIF. Source and license fields mandatory.
